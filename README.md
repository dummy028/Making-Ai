# Making AI — 초간단 커스텀 AI 캐릭터 채팅

ChatGPT를 극단적으로 단순화한 **로컬 웹앱**입니다. 로그인도 DB 서버도 없고, 모든 데이터는 `data/` 폴더 하나에 파일로 저장됩니다.

- 캐릭터(페르소나)와 메신저처럼 짧게 대화
- 감정/상황 이미지 태그(`[img:joy]`)로 대사 옆에 표정 표시
- 지침·스킬·기억을 md 파일로 관리 (AI도 직접 읽고 씀 — Rule 폴더 안에서만)
- Claude · ChatGPT · Gemini · Grok · Qwen · DeepSeek · GLM · Kimi 지원, 대화 중 모델 전환

---

## 실행

1. [Node.js](https://nodejs.org) **18 이상** (LTS 권장) 설치. `npm install` 같은 추가 설치는 필요 없습니다.
2. 실행 스크립트 실행
   - **Windows**: `start.bat` 더블클릭
   - **macOS**: `start.command` 더블클릭 (처음 한 번은 우클릭 → 열기)
   - **Linux**: `./start.sh`
3. 브라우저가 자동으로 `http://localhost:3939` 를 엽니다. (포트가 사용 중이면 3940, 3941… 순으로 시도)
4. 처음엔 **"API 키를 연결하세요"** 화면이 나옵니다. 키를 하나 넣으면 해당 제공사의 모델 목록을 자동으로 불러옵니다.

> USB 휴대용으로 쓰려면 이 폴더 안에 휴대용 Node를 넣어두세요: Windows는 `node\node.exe`, macOS/Linux는 `node/bin/node`. 실행 스크립트가 그걸 먼저 사용합니다.

종료는 실행 창(터미널)을 닫으면 됩니다.

## 데이터 폴더

```
data/
  rules/                      ← 전역. AI가 읽기/쓰기 가능한 유일한 폴더
    instructions/*.md         ← 지침 (항상 적용, 하위 폴더 가능)
    memory/*.md               ← 기억 (항상 적용, AI가 대화 중 추가)
    skills/<스킬명>/SKILL.md  ← 스킬 (설명만 항상, 본문은 필요할 때 로드)
  personas/<ID>/
    persona.md                ← 페르소나 설정 (## 이름, ## 나이 … 섹션)
    images/                   ← 감정/상황 이미지 + images.json(설명)
  projects/<프로젝트명>/chats/<채팅ID>.json
  assets/                     ← 채팅 배경 이미지
  settings.json               ← 테마, 색상, 기본 모델/페르소나
  keys.json                   ← API 키
  models.json                 ← 불러온 모델 목록 캐시
```

- `data/` 폴더만 복사하면 다른 PC에서 그대로 이어서 쓸 수 있습니다. 앱을 업데이트할 때도 `data/`만 유지하면 됩니다.
- 설정 → **데이터**에서 zip으로 내보내기/가져오기가 가능합니다. 가져오기 전 현재 데이터는 `data_backup_<시간>/` 으로 자동 보관됩니다.
- 다른 위치에 두고 싶으면 환경변수 `DATA_DIR` 로 경로를 지정할 수 있습니다.

## 사용법

### 페르소나
사이드바 **🎭 페르소나**에서 생성/편집/복제/삭제. 상단의 페르소나 버튼으로 대화 중 전환.
필수: 이름·나이·성격·말투·설명 / 선택: 스토리, 말투 예시, 가치관, 강점·약점, 좋아하는 것·싫어하는 것, 사고방식, 욕망, 습관, 기타 설정집.

### 감정/상황 이미지 프로토콜
- 페르소나 편집 화면에 이미지를 **끌어다 놓으면** 파일명이 코드가 됩니다. `joy.png` → `[img:joy]`
- 각 이미지에 "언제 보여줄지" 설명을 적으면 AI가 그 설명을 보고 태그를 고릅니다.
- AI는 대사 앞에 `[img:코드]` 를 붙이고, 앱은 태그를 숨긴 채 해당 이미지를 대사 옆에 표시합니다. 한 답변에 태그가 여러 개면 말풍선이 나뉩니다.
- 태그가 없거나 없는 코드면 **기본 이미지**(`default.*`, 없으면 첫 번째 이미지)를 씁니다.
- 행동 코드: `*웃으며*` 처럼 별표로 감싼 부분은 회색 기울임체 행동 묘사로 표시됩니다.

### 지침 · 스킬 (Rule 폴더)
사이드바 **📜 지침 · 스킬**에서 md 파일을 직접 보고 편집합니다. (Ctrl+S 저장)
- 메시지를 보낼 때마다 Rule 폴더를 새로 읽어 시스템 프롬프트에 넣습니다. 파일을 고치면 다음 메시지부터 바로 반영됩니다.
- 지침 맨 위 frontmatter의 `trigger` 로 적용 방식을 정할 수 있습니다 (Antigravity 방식 참고):
  - `always_on` (기본) — 항상 적용
  - `model_decision` — `description` 만 넣고, AI가 필요할 때 본문을 읽음
  - `off` — 사용 안 함
- 스킬은 `skills/<이름>/SKILL.md` 에 `name`, `description` frontmatter를 넣습니다. 평소엔 설명만 넣어 토큰을 아끼고, AI가 필요하다고 판단하면 본문을 읽습니다.
- 기본 지침: 대화 스타일(짧고 간결하게), 검색(모르면 반드시 검색), 기억 저장. 마음대로 고쳐 쓰세요.
- AI에게 "앞으로 나를 ○○이라고 불러줘" 같이 말하면 `규칙-관리` 스킬을 통해 지침 파일로 저장합니다.

## 알아두셔야 할 점

### 🔐 보안
- **API 키는 `data/keys.json`에 평문으로 저장됩니다.** USB를 잃어버리면 키도 유출됩니다. 각 제공사 콘솔에서 **월 사용 한도(spend limit)** 를 걸어두는 걸 강력히 권장합니다.
- zip 내보내기는 기본적으로 **키를 제외**합니다. ("API 키 포함" 체크 시에만 포함) 키가 없는 zip을 가져오면 현재 키가 유지됩니다.
- 서버는 `127.0.0.1`(이 PC)에서만 열립니다. 같은 와이파이의 다른 기기에서는 접속할 수 없습니다(의도된 동작). 다른 웹사이트가 이 로컬 서버를 몰래 호출하는 것도 Host/Origin 검사로 막습니다.
- AI의 파일 권한은 **`data/rules/` 안의 `.md` 파일 생성·수정·읽기**로만 제한됩니다. `..` 경로, 절대 경로, 심볼릭 링크로 밖을 가리키는 경로는 모두 차단되고, 삭제 권한은 없습니다.
- 다만 AI가 지침/기억을 **덮어쓸 수 있으므로**, 웹 검색 결과에 섞인 이상한 지시(프롬프트 인젝션)가 지침·기억에 저장될 가능성은 0이 아닙니다. 채팅에 `📝 … 저장함` 표시가 뜨면 가끔 편집기에서 내용을 확인하세요.

### 💸 비용
- 메시지 하나마다 **시스템 프롬프트(페르소나 + 지침 + 기억 + 스킬 설명) + 최근 대화(최대 60개 / 약 4만 자)** 가 함께 전송됩니다. 대화가 길어질수록 입력 토큰이 늘어납니다. 주제가 바뀌면 새 채팅을 여는 게 저렴합니다.
- 지침·기억 파일은 **매 요청마다** 들어가므로 짧게 유지할수록 좋습니다. 스킬은 설명만 들어가서 많아도 부담이 적습니다.
- 프롬프트 캐시: Claude는 시스템 프롬프트와 대화 기록에 캐시를 명시적으로 걸고, 나머지 제공사는 자동 캐시(제공사별 정책)를 탑니다. 현재 시각 정보는 시스템 프롬프트가 아니라 마지막 메시지 끝에 붙여 캐시가 깨지지 않게 했습니다.
- **웹 검색은 별도 과금**됩니다 (Claude 웹 검색, OpenAI web_search 도구, Gemini Google 검색 그라운딩, Grok 검색, Qwen/GLM/Kimi 검색 모두 토큰과 별개의 요금 또는 무료 한도가 있음). 정확한 금액은 각 제공사 가격표를 확인하세요. Tavily/Brave 외부 검색도 각자 무료 한도 이후 유료입니다.
- 추론(thinking) 모델은 화면에 안 보이는 사고 과정도 출력 토큰으로 청구됩니다. 최신 Claude(Opus 5.5 등)는 사고를 끌 수 없어서 `effort: low` 로, OpenAI o/gpt-5 계열은 `reasoning.effort: low` 로 보내 비용과 지연을 줄였습니다.
- "짧게 말하기" 기본 지침은 출력 토큰도 아껴줍니다.

### 🤖 모델별 차이

| 제공사 | 웹 검색 방식 | 참고 |
|---|---|---|
| Claude | 내장 `web_search` 서버 도구 | 최신 모델은 `web_search_20260209`, 지원 안 하는 모델은 구버전 → 검색 없음 순으로 자동 전환. Opus 5.5·Sonnet 5.5·Opus 5·Fable 5.1은 안전 분류기가 거절하면 **서버측 대체 모델(fallbacks)** 이 자동으로 이어 답합니다(답변 메타에 실제 모델 표시). |
| ChatGPT | Responses API `web_search` 도구 | 검색 도구를 지원하지 않는 구형 모델은 외부 검색으로 자동 전환 |
| Gemini | Google 검색 그라운딩 | 일부 모델은 **검색과 함수 호출을 동시에 못 씁니다** → 이때는 검색을 우선하므로 그 모델은 지침/기억 파일을 쓰지 못합니다. 안전 필터는 가장 느슨한 단계(BLOCK_NONE)로 요청합니다. |
| Grok | Responses API `web_search` 도구 | 예전 Live Search(`search_parameters`)는 xAI가 폐지 |
| Qwen | `enable_search` | 국제/중국/미국 리전 키를 자동 감지 |
| DeepSeek | **내장 검색 없음** → 외부 검색 | 설정에서 Tavily 또는 Brave 키를 넣는 걸 권장. 없으면 DuckDuckGo로 대체(불안정) |
| GLM | `web_search` 도구 | z.ai(국제)/bigmodel.cn(중국) 키 자동 감지. 모델 목록 API가 안 되면 기본 목록을 쓰고, 목록에 없는 모델은 직접 입력 |
| Kimi | `$web_search` 내장 도구 | Moonshot이 아직 프로덕션 사용을 권장하지 않는 기능이라 실패하면 외부 검색으로 전환 |

- **모델 목록**은 키를 넣을 때 제공사 API에서 불러오고, 텍스트 대화용 모델만 걸러 보여줍니다(임베딩·음성·이미지/영상 생성 모델 제외). 새 모델이 나오면 설정의 "모델 목록 새로고침", 목록에 없으면 모델 선택창에 ID를 직접 입력하세요.
- 내장 검색이나 도구 호출이 안 되는 모델은 앱이 **자동으로 기능을 한 단계씩 줄여** 다시 시도합니다(내장 검색 → 외부 검색 → 도구 없음). 도구가 없는 모델은 검색·기억 저장을 할 수 없습니다.
- **이미지 태그를 지키는 정도는 모델마다 다릅니다.** 작은/저가 모델은 태그를 빼먹거나 없는 코드를 쓰기도 합니다(그때는 기본 이미지로 표시).
- 앱 자체의 추가 검열은 없습니다. 다만 각 제공사의 정책 필터는 그대로 적용됩니다(거절 시 ⚠ 안내 표시).

### 📏 제약
- 사용자가 이미지를 첨부해 보내는 기능(비전)은 넣지 않았습니다.
- 모델에는 최근 대화(최대 60개 / 약 4만 자)만 전달됩니다. 오래된 내용은 모델이 기억하지 못하니, 오래 기억해야 할 건 **기억(memory)** 에 남기세요.
- 응답이 나오는 동안에는 다른 채팅으로 이동할 수 없습니다(Esc 또는 ■ 버튼으로 중지 가능, 중지된 부분은 저장됨).
- 같은 `data/` 폴더를 여러 PC에서 **동시에** 열면(클라우드 동기화 폴더 등) 저장 충돌이 날 수 있습니다.
- zip 내보내기/가져오기는 4GB 미만만 지원합니다.
